## Important design note
The social platforms did not expose their full live media library to the research tools, so the website uses an original CSS/illustration art direction rather than copying unverified social photographs. This keeps the demo functional while avoiding fake or mismatched imagery.

For the final client version, replace the CSS illustrations with Donutello-approved product/store photography and the official logo asset supplied by the team.
